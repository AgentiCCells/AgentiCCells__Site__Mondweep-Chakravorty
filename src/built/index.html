SGit x Ruflo: what if an agent loses its workspace?

Mondweep built a proof of concept joining SGit and Ruflo, shown in a 104.7-second video of a twelve-step run:

  1. Ruflo's memory is saved as an encrypted SGit checkpoint, under an Agent Behaviour Policy.
  2. The project is deleted.
  3. The memory is restored in a fresh process, with the same SHA-256 fingerprint as before.
  4. Three safeguards held throughout the run.

A follow-up article looks at when the vault is actually used.

Sources (newsroom.sgit.ai): What if an agent loses its workspace? and When is the vault actually used? The video length and step count are from the first article.
